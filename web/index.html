Pay-per-query data for AI agents, settled on Arc

Each API call costs 0.001 USDC and is paid on-chain on Arc, where USDC is also the gas token, so an agent needs one asset and no account. The API answers 402 Payment Required with the exact transaction to send. The agent pays, retries with the tx hash, and the server checks the receipt on Arc before returning the data. The dataset is official state WARN Act layoff notices (TX TWC and CA EDD).
